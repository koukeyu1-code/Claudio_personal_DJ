# 音频文件说明

将你的音频文件放在此目录下，可通过 `/audio/文件名.mp3` 访问。

## 示例文件结构

```
audio/
├── demo.mp3          # 演示音频
├── morning-jazz.mp3  # 早晨爵士
└── focus.mp3         # 专注音乐
```

## 免费音乐来源

1. **Pixabay Music** - https://pixabay.com/music/
   - 免费，无需署名
   - 可直接下载MP3

2. **Free Music Archive** - https://freemusicarchive.org/
   - 大量CC授权音乐

3. **Bensound** - https://www.bensound.com/
   - 免费版可供个人使用

下载后放到此目录，然后在 `musicService.ts` 中添加对应曲目信息。
